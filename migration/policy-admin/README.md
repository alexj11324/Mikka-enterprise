The extracted HTTP implementation is under `extensions/policy-admin/`. Its source is public PR264 at721bbf plus the reviewed a3ed508 safety patch recorded on evidence branch2050898. The patch changes execution authorization in public runtime; it does not change `handlePolicy`, `http.ts` or the management route. `source-map.json` preserves original commit/author/blob attribution. AGPL and existing notices remain applicable.

`CorePolicyAdmin` exposes only read/current/publish and public signing metadata. The enterprise adapter has no SQL pool, membership mutator, signing private key, enrollment switch or execution-admission API. Core document schema and typed errors remain authoritative. A core binding must wrap methods, pass only public signer fields and resolve a genuine session with `disableCookieCache:true`; it must not forward the complete PolicyStore/signer instance to enterprise code.

The route factory contains real GET/POST transport behavior, including strict JSON schema validation, 64KiB limit, browser-session-only authentication, Origin/cross-site checks, historical versions, effective/revoked readback, CAS errors, publish and rollback delegation. The runtime wrapper fails closed on missing/unavailable core services. It does not register a global bypass or claim enrolled tenants become unmanaged.
